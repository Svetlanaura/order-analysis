Order Analysis — анализ заказов интернет-магазина

Описание проекта

Учебный проект на Python для пакетной обработки CSV-файлов с заказами интернет-магазина.

Функциональность

Автоматический поиск и обработка CSV-файлов.

Фильтрация заказов со статусом Delivered.

Расчёт общей выручки, среднего чека и количества заказов.

Обработка повреждённых файлов без остановки программы.

Логирование ошибок.

Сохранение итогового отчёта в CSV.

Запуск проекта

Перейдите в папку order_analysis и выполните:

python -m pip install -r requirements.txt
python run.py

Отчёт сохраняется в reports/summary_report.csv.

Используемые технологии

Python 3.11, pandas.
